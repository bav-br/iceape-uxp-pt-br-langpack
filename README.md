### Pacote de idiomas em Português Brasil para o navegador iceape-UXP
Baseado no pacote de idiomas russo feito por Zanud

Tradução feita com base nos arquivos de idioma pt-BR do Seamonkey 2.53

**Instalação:**
1. Baixe a versão de tradução desejada na página _Releases_
2. Arraste o .xpi baixado para a janela do iceape-UXP
3. Confirme a instalação da extensão
4. Agora você realmente precisa mudar o idioma. Existem 2 maneiras:
   - (Recomendado) Na barra de menus, acesse Editar > Preferências e vá na categoria Aparência e, em Linguagem de interface, selecione a opção Português (Brasil).
   - *Ou* abra about:config e altere o valor de general.useragent.locale de "en-US" para "pt-BR"
5. Reinicie seu navegador
